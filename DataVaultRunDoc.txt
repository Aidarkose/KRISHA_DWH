  Как пользоваться                                                                           
                                                                                           
  Поднять стек:                                                                              
  cd /home/daurena2609/KRISHA_DWH
  docker compose build dbt-dv                                                                
  docker compose up -d postgres dbt-dv                                                       
                                      
  Установить пакеты + проверить подключение:                                                 
  docker exec krisha_dbt_dv dbt deps  --profiles-dir /dbt                                    
  docker exec krisha_dbt_dv dbt debug --profiles-dir /dbt
                                                                                             
  Полный билд DV (хабы + линки + сателлиты + 22 теста):                                      
  docker exec krisha_dbt_dv dbt build --select dv --profiles-dir /dbt                        
                                                                                             
  Только запустить (без тестов):                                                             
  docker exec krisha_dbt_dv dbt run --select dv --profiles-dir /dbt                        
                                                                                             
  Полная пере-загрузка (truncate + insert):                                                
  docker exec krisha_dbt_dv dbt run --select dv --full-refresh --profiles-dir /dbt           
                                                                                           
  Только тесты:                                                                              
  docker exec krisha_dbt_dv dbt test --select dv --profiles-dir /dbt                       
                                                                                             
  Граф зависимостей:                                                                         
  docker exec krisha_dbt_dv dbt list --select +sat_listing_price --profiles-dir /dbt
                                                                                             
  Точечно построить один satellite:                                                          
  docker exec krisha_dbt_dv dbt run --select sat_listing_attributes+ --profiles-dir /dbt     
                                                                                             
  Как добавить новую DV-сущность через AutomateDV                                            
                                                                                           
  1. В stg_dv_listings.sql (или новый stage-файл) добавить hash-колонку — automate_dv.stage()
   сам соберёт MD5 из набора:                                                              
  hashed_columns:                                                                            
    HK_NEW_ENTITY:                                                                           
      - "natural_key_column"
  2. Создать hub_<entity>.sql — макрос automate_dv.hub(src_pk, src_nk, src_ldts, src_source, 
  source_model).                                                                             
  3. Если нужны связи — lnk_<a>_<b>.sql через automate_dv.link(src_pk, src_fk=[…], …).       
  4. Описательные атрибуты — sat_<entity>.sql через automate_dv.sat(src_pk, src_hashdiff,    
  src_payload=[…], src_ldts, src_source, source_model). Hashdiff в stage (is_hashdiff: true) 
  автоматически даёт SCD2.                                                                   
  5. Прописать тесты в _dv.yml (unique/not_null на хеш-ключ, relationships на хабы).         
                                                                                             
  Загрузка DAG-ами при этом не меняется — пока Airflow → stg.listings →                      
  marts.fact_listing_price_history идёт штатно, dbt-DV над ним строится автоматически по     
  расписанию (можно повесить отдельный DAG, дёргающий dbt run --select dv).
